# Hivemind API Reference Guide

## Overview

The Hivemind API provides comprehensive access to Twitter/X data and collective action capabilities through a distributed network of connected bot accounts. This guide helps Claude agents implement Hivemind skills.

## Base URL

Production: `https://hive.pepes.dog/api/hivemind`

## Authentication

All Hivemind API endpoints require authentication via API key.

### API Key Header

```
X-API-Key: <your-hivemind-api-key>
```

### Example Request

```bash
curl -X GET "https://hive.pepes.dog/api/hivemind/twitter/users/elonmusk" \
  -H "X-API-Key: your-hivemind-api-key"
```

## Core Concepts

### 1. Hivemind Network
- Distributed network of Twitter bot accounts
- Collective action capabilities (likes, retweets, follows)
- Real-time status monitoring
- Coordinated tweet promotion (raids)

### 2. TwitterAPI.io Backend
- All Twitter data queries use TwitterAPI.io
- No Twitter API rate limits
- Fast response times (avg 700ms)
- Up to 200 requests per second

### 3. Pagination
- Cursor-based pagination for all list endpoints
- Default page size: 20-200 items (varies by endpoint)
- Always returns newest items first

## API Endpoints

### 1. Search Tweets

Search for tweets by keyword or query.

**Endpoint:** `GET /twitter/search`

**Headers:**
- `X-API-Key`: Your Hivemind API key (required)

**Query Parameters:**
- `q` (string, required): Search query (supports Twitter search operators)
- `count` (number): Results per page (default: 20, max: 100)
- `cursor` (string): Pagination cursor for next page
- `from` (string): Filter tweets from specific user
- `to` (string): Filter tweets to specific user
- `lang` (string): Language filter (e.g., "en", "es")
- `filter` (string): Additional filters (e.g., "verified", "has_media")

**Example Request:**
```bash
curl -X GET "https://hive.pepes.dog/api/hivemind/twitter/search?q=bitcoin&count=50" \
  -H "X-API-Key: your-hivemind-api-key"
```

## Error Handling

### Error Response Format

All errors follow this format:

```json
{
  "error": "Error message",
  "details": "Additional error details (optional)",
  "code": "ERROR_CODE (optional)"
}
```

### Common Error Codes

- `401 Unauthorized`: Missing or invalid API key
- `400 Bad Request`: Invalid parameters
- `404 Not Found`: Resource not found
- `429 Too Many Requests`: Rate limit exceeded (rare with TwitterAPI.io)
- `500 Internal Server Error`: Server error
- `502 Bad Gateway`: TwitterAPI.io error

### Error Handling Example (JavaScript)

```javascript
async function searchTweets(query, apiKey) {
  try {
    const response = await fetch(
      `https://hive.pepes.dog/api/hivemind/twitter/search?q=${encodeURIComponent(query)}`,
      {
        headers: {
          'X-API-Key': apiKey
        }
      }
    );

    if (!response.ok) {
      const error = await response.json();
      console.error(`API Error: ${error.error}`);

      // Handle specific errors
      if (response.status === 401) {
        throw new Error('Invalid API key');
      } else if (response.status === 429) {
        // Wait and retry
        await new Promise(resolve => setTimeout(resolve, 1000));
        return searchTweets(query, apiKey);
      }

      throw new Error(error.error || 'Unknown error');
    }

    return await response.json();
  } catch (error) {
    console.error('Request failed:', error);
    throw error;
  }
}
```

## Rate Limits

### TwitterAPI.io Backend
- **No hard rate limits** on Twitter data queries
- Supports up to **200 requests per second**
- Average response time: **700ms**

### Hivemind Actions
- Raid submissions: **1 per tweet per 24 hours** (duplicate prevention)
- Raid execution: **Async processing** (no timeout concerns)

## Best Practices

### 1. Pagination

Always implement pagination for list endpoints:

```javascript
async function getAllFollowers(username, apiKey) {
  const followers = [];
  let cursor = null;
  let hasMore = true;

  while (hasMore) {
    const url = new URL(`https://hive.pepes.dog/api/hivemind/twitter/users/${username}/followers`);
    if (cursor) url.searchParams.set('cursor', cursor);

    const response = await fetch(url, {
      headers: { 'X-API-Key': apiKey }
    });

    const data = await response.json();
    followers.push(...data.data.users);

    cursor = data.data.next_cursor;
    hasMore = data.data.has_more;
  }

  return followers;
}
```

### 2. Error Handling

Implement robust error handling with retries:

```javascript
async function apiCallWithRetry(url, options, maxRetries = 3) {
  for (let i = 0; i < maxRetries; i++) {
    try {
      const response = await fetch(url, options);

      if (response.status === 502) {
        // TwitterAPI.io temporary issue, wait and retry
        await new Promise(resolve => setTimeout(resolve, 2000 * (i + 1)));
        continue;
      }

      if (!response.ok) {
        const error = await response.json();
        throw new Error(error.error || `HTTP ${response.status}`);
      }

      return await response.json();
    } catch (error) {
      if (i === maxRetries - 1) throw error;
      await new Promise(resolve => setTimeout(resolve, 1000 * (i + 1)));
    }
  }
}
```

### 3. Caching

Implement caching for frequently accessed data:

```javascript
const cache = new Map();

async function getCachedUserProfile(username, apiKey) {
  const cacheKey = `user:${username}`;
  const cached = cache.get(cacheKey);

  if (cached && Date.now() - cached.timestamp < 5 * 60 * 1000) {
    return cached.data;
  }

  const data = await fetch(
    `https://hive.pepes.dog/api/hivemind/twitter/users/${username}`,
    { headers: { 'X-API-Key': apiKey } }
  ).then(r => r.json());

  cache.set(cacheKey, {
    data,
    timestamp: Date.now()
  });

  return data;
}
```

### 4. Batch Operations

Use batch endpoints when available:

```javascript
async function getTweetDetails(tweetIds, apiKey) {
  // For multiple tweets, make parallel requests
  const promises = tweetIds.map(id =>
    fetch(`https://hive.pepes.dog/api/hivemind/twitter/tweets/${id}`, {
      headers: { 'X-API-Key': apiKey }
    }).then(r => r.json())
  );

  return Promise.all(promises);
}
```

## Implementation Examples

### Example 1: Twitter Search Monitor

Monitor Twitter for specific keywords and track engagement:

```javascript
class TwitterMonitor {
  constructor(apiKey) {
    this.apiKey = apiKey;
    this.baseUrl = 'https://hive.pepes.dog/api/hivemind';
  }

  async monitorKeyword(keyword, interval = 60000) {
    let lastTweetId = null;

    setInterval(async () => {
      try {
        const response = await fetch(
          `${this.baseUrl}/twitter/search?q=${encodeURIComponent(keyword)}&count=10`,
          { headers: { 'X-API-Key': this.apiKey } }
        );

        const data = await response.json();
        const tweets = data.data.tweets;

        if (tweets.length > 0 && tweets[0].id !== lastTweetId) {
          // New tweets found
          const newTweets = lastTweetId
            ? tweets.filter(t => t.id > lastTweetId)
            : tweets;

          for (const tweet of newTweets) {
            console.log(`New tweet: ${tweet.text}`);

            // Check engagement
            if (tweet.metrics.like_count > 1000) {
              console.log('High engagement tweet detected!');
              // Submit for promotion
              await this.submitForPromotion(tweet);
            }
          }

          lastTweetId = tweets[0].id;
        }
      } catch (error) {
        console.error('Monitor error:', error);
      }
    }, interval);
  }

  async submitForPromotion(tweet) {
    const tweetUrl = `https://twitter.com/${tweet.author.username}/status/${tweet.id}`;

    const response = await fetch(`${this.baseUrl}/raids`, {
      method: 'POST',
      headers: {
        'X-API-Key': this.apiKey,
        'Content-Type': 'application/json'
      },
      body: JSON.stringify({ tweetUrl })
    });

    if (response.ok) {
      console.log('Tweet submitted for promotion');
    }
  }
}
```

### Example 2: User Analysis

Analyze a user's Twitter profile and network:

```javascript
class UserAnalyzer {
  constructor(apiKey) {
    this.apiKey = apiKey;
    this.baseUrl = 'https://hive.pepes.dog/api/hivemind';
  }

  async analyzeUser(username) {
    // Get user profile
    const profile = await this.getProfile(username);

    // Get recent tweets
    const tweets = await this.getTweets(username);

    // Get follower sample
    const followers = await this.getFollowerSample(username);

    // Calculate metrics
    const analysis = {
      profile: {
        username: profile.data.username,
        followers: profile.data.followers_count,
        following: profile.data.following_count,
        tweets: profile.data.tweet_count,
        verified: profile.data.verified
      },
      engagement: this.calculateEngagement(tweets.data.tweets),
      followerQuality: this.analyzeFollowers(followers.data.users),
      influence: this.calculateInfluenceScore(profile.data, tweets.data.tweets)
    };

    return analysis;
  }

  calculateEngagement(tweets) {
    const totalEngagement = tweets.reduce((sum, tweet) => {
      return sum + tweet.metrics.like_count +
             tweet.metrics.retweet_count * 2 +
             tweet.metrics.reply_count * 1.5;
    }, 0);

    return {
      averagePerTweet: totalEngagement / tweets.length,
      topTweet: tweets.sort((a, b) =>
        b.metrics.like_count - a.metrics.like_count
      )[0]
    };
  }

  analyzeFollowers(followers) {
    const verifiedCount = followers.filter(f => f.verified).length;
    const avgFollowers = followers.reduce((sum, f) =>
      sum + f.followers_count, 0
    ) / followers.length;

    return {
      verifiedPercentage: (verifiedCount / followers.length) * 100,
      averageFollowerCount: avgFollowers,
      quality: avgFollowers > 1000 ? 'High' : 'Medium'
    };
  }

  calculateInfluenceScore(profile, tweets) {
    const followerScore = Math.log10(profile.followers_count + 1) * 10;
    const engagementRate = tweets.reduce((sum, t) =>
      sum + (t.metrics.like_count / profile.followers_count), 0
    ) / tweets.length * 100;
    const verifiedBonus = profile.verified ? 20 : 0;

    return Math.min(100, followerScore + engagementRate + verifiedBonus);
  }
}
```

### Example 3: Raid Campaign Manager

Manage tweet promotion campaigns:

```javascript
class RaidCampaignManager {
  constructor(apiKey) {
    this.apiKey = apiKey;
    this.baseUrl = 'https://hive.pepes.dog/api/hivemind';
  }

  async createCampaign(tweets) {
    const results = [];

    for (const tweetUrl of tweets) {
      try {
        // Submit raid
        const raid = await this.submitRaid(tweetUrl);

        // Execute immediately
        await this.executeRaid(raid.raid.id);

        results.push({
          tweetUrl,
          raidId: raid.raid.id,
          status: 'submitted'
        });

        // Wait between submissions
        await new Promise(resolve => setTimeout(resolve, 2000));
      } catch (error) {
        results.push({
          tweetUrl,
          status: 'failed',
          error: error.message
        });
      }
    }

    return results;
  }

  async submitRaid(tweetUrl) {
    const response = await fetch(`${this.baseUrl}/raids`, {
      method: 'POST',
      headers: {
        'X-API-Key': this.apiKey,
        'Content-Type': 'application/json'
      },
      body: JSON.stringify({ tweetUrl })
    });

    if (!response.ok) {
      throw new Error('Failed to submit raid');
    }

    return response.json();
  }

  async executeRaid(raidId) {
    const response = await fetch(
      `${this.baseUrl}/raids/${raidId}/execute`,
      {
        method: 'POST',
        headers: { 'X-API-Key': this.apiKey }
      }
    );

    return response.json();
  }

  async monitorCampaign(raidIds) {
    const statuses = [];

    for (const raidId of raidIds) {
      const raids = await fetch(
        `${this.baseUrl}/raids?limit=100`,
        { headers: { 'X-API-Key': this.apiKey } }
      ).then(r => r.json());

      const raid = raids.raids.find(r => r.id === raidId);
      if (raid) {
        statuses.push({
          id: raidId,
          status: raid.status,
          likes: raid.likesCount,
          retweets: raid.retweetsCount,
          totalEngagement: raid.likesCount + raid.retweetsCount
        });
      }
    }

    return statuses;
  }
}
```

## Security Best Practices

### 1. API Key Management

- **Never** expose API keys in client-side code
- Use environment variables for API keys
- Rotate API keys regularly
- Use different API keys for different environments

### 2. Request Validation

- Always validate URLs before submitting raids
- Sanitize user input before sending to API
- Implement request size limits
- Use HTTPS for all API calls

### 3. Rate Limiting

Even though TwitterAPI.io doesn't have strict rate limits:
- Implement client-side rate limiting to prevent abuse
- Use exponential backoff for retries
- Monitor API usage patterns

## Troubleshooting

### Common Issues and Solutions

1. **401 Unauthorized**
   - Check API key is correct
   - Verify API key is included in header
   - Ensure header name is exactly `X-API-Key`

2. **502 Bad Gateway**
   - TwitterAPI.io temporary issue
   - Implement retry with exponential backoff
   - Check TwitterAPI.io status

3. **Duplicate Raid Submission**
   - Same tweet can only be submitted once per 24 hours
   - Check raid exists before submitting

4. **Pagination Not Working**
   - Ensure cursor is properly encoded in URL
   - Check `has_more` field before requesting next page

5. **Empty Response Data**
   - User might not exist
   - Tweet might be deleted
   - Search query might have no results
