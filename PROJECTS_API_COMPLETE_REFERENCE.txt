# Projects API Complete Reference Guide

## Overview

The Projects API provides isolated Twitter/X data access for individual projects. Each project has its own API key and data isolation, perfect for building applications that need Twitter data without rate limits.

## Base URL

Production: `https://hive.pepes.dog/api/projects/{projectId}`

## Critical Information: projectId Parameter

**The `projectId` is a REQUIRED path parameter that MUST be included in the URL path.**

❌ **WRONG:** `/api/projects/twitter/search?projectId=cmj4h4o5y0000gy04oss0g3o9`
✅ **CORRECT:** `/api/projects/cmj4h4o5y0000gy04oss0g3o9/twitter/search`

- **Location**: Always in the URL path, NEVER as a query parameter
- **Format**: String (e.g., `cmj4h4o5y0000gy04oss0g3o9`)
- **Required**: YES, for all Projects API endpoints

## Authentication

Projects API uses Bearer token authentication.

### Authentication Header

```
Authorization: Bearer <your-project-api-key>
```

### Example Request

```bash
curl -X GET "https://hive.pepes.dog/api/projects/cmj4h4o5y0000gy04oss0g3o9/twitter/users/elonmusk" \
  -H "Authorization: Bearer bta_0fdd9a3a057ef1c474079a93b04e2515d2ef000e568d80d71e69f0ec57ce4d03"
```

## Core Concepts

### 1. Project Isolation
- Each project operates independently
- Separate API keys per project
- No data sharing between projects
- Independent rate limiting

### 2. TwitterAPI.io Backend
- All Twitter queries proxied through TwitterAPI.io
- No Twitter API rate limits
- Average response time: 700ms
- Up to 200 requests per second

### 3. Pagination
- Cursor-based pagination for list endpoints
- Page sizes: 20-200 items (varies by endpoint)
- Always returns newest items first

## API ENDPOINTS

### 1. Search Tweets

Search for tweets using Twitter's advanced search syntax.

**Endpoint:** `GET /api/projects/{projectId}/twitter/search`

**Path Parameters:**
- `projectId` (string, required): Your project ID

**Headers:**
- `Authorization`: Bearer token (required)

**Query Parameters:**
- `q` (string, required): Search query (supports Twitter search operators)
- `count` (number): Results per page (default: 20, max: 100)
- `cursor` (string): Pagination cursor for next page
- `from` (string): Filter tweets from specific user
- `to` (string): Filter tweets to specific user
- `lang` (string): Language filter (e.g., "en", "es")
- `filter` (string): Additional filters (e.g., "verified", "has_media")

**Example Request:**
```bash
curl -X GET "https://hive.pepes.dog/api/projects/cmj4h4o5y0000gy04oss0g3o9/twitter/search?q=bitcoin&count=50" \
  -H "Authorization: Bearer bta_0fdd9a3a057ef1c474079a93b04e2515d2ef000e568d80d71e69f0ec57ce4d03"
```

**Response:**

## Error Handling

### Error Response Format

All errors follow this format:

```json
{
  "error": "Error message",
  "details": "Additional error details (optional)",
  "code": "ERROR_CODE (optional)"
}
```

### Common Error Codes

- `401 Unauthorized`: Missing or invalid Bearer token
- `400 Bad Request`: Invalid parameters or missing projectId
- `404 Not Found`: Resource not found or invalid projectId
- `429 Too Many Requests`: Rate limit exceeded (rare with TwitterAPI.io)
- `500 Internal Server Error`: Server error
- `502 Bad Gateway`: TwitterAPI.io error

### Error Handling Example (JavaScript)

```javascript
async function searchTweetsForProject(projectId, query, apiKey) {
  try {
    const response = await fetch(
      `https://hive.pepes.dog/api/projects/${projectId}/twitter/search?q=${encodeURIComponent(query)}`,
      {
        headers: {
          'Authorization': `Bearer ${apiKey}`
        }
      }
    );

    if (!response.ok) {
      const error = await response.json();
      console.error(`API Error: ${error.error}`);

      // Handle specific errors
      if (response.status === 401) {
        throw new Error('Invalid API key or projectId');
      } else if (response.status === 429) {
        // Wait and retry
        await new Promise(resolve => setTimeout(resolve, 1000));
        return searchTweetsForProject(projectId, query, apiKey);
      }

      throw new Error(error.error || 'Unknown error');
    }

    return await response.json();
  } catch (error) {
    console.error('Request failed:', error);
    throw error;
  }
}
```

## Best Practices

### 1. Always Include projectId in Path

```javascript
// ✅ CORRECT
const url = `https://hive.pepes.dog/api/projects/${projectId}/twitter/users/elonmusk`;

// ❌ WRONG
const url = `https://hive.pepes.dog/api/projects/twitter/users/elonmusk?projectId=${projectId}`;
```

### 2. Implement Pagination

```javascript
async function getAllFollowersForProject(projectId, username, apiKey) {
  const followers = [];
  let cursor = null;
  let hasMore = true;

  while (hasMore) {
    const url = new URL(`https://hive.pepes.dog/api/projects/${projectId}/twitter/users/${username}/followers`);
    if (cursor) url.searchParams.set('cursor', cursor);

    const response = await fetch(url, {
      headers: { 'Authorization': `Bearer ${apiKey}` }
    });

    const data = await response.json();
    followers.push(...data.data.users);

    cursor = data.data.next_cursor;
    hasMore = data.data.has_more;
  }

  return followers;
}
```

### 3. Handle Errors Gracefully

```javascript
async function apiCallWithRetry(projectId, endpoint, apiKey, maxRetries = 3) {
  const baseUrl = `https://hive.pepes.dog/api/projects/${projectId}`;

  for (let i = 0; i < maxRetries; i++) {
    try {
      const response = await fetch(`${baseUrl}${endpoint}`, {
        headers: { 'Authorization': `Bearer ${apiKey}` }
      });

      if (response.status === 502) {
        // TwitterAPI.io temporary issue
        await new Promise(resolve => setTimeout(resolve, 2000 * (i + 1)));
        continue;
      }

      if (!response.ok) {
        const error = await response.json();
        throw new Error(error.error || `HTTP ${response.status}`);
      }

      return await response.json();
    } catch (error) {
      if (i === maxRetries - 1) throw error;
      await new Promise(resolve => setTimeout(resolve, 1000 * (i + 1)));
    }
  }
}
```

### 4. Cache Responses

```javascript
const cache = new Map();

async function getCachedUserProfileForProject(projectId, username, apiKey) {
  const cacheKey = `${projectId}:user:${username}`;
  const cached = cache.get(cacheKey);

  if (cached && Date.now() - cached.timestamp < 5 * 60 * 1000) {
    return cached.data;
  }

  const data = await fetch(
    `https://hive.pepes.dog/api/projects/${projectId}/twitter/users/${username}`,
    { headers: { 'Authorization': `Bearer ${apiKey}` } }
  ).then(r => r.json());

  cache.set(cacheKey, {
    data,
    timestamp: Date.now()
  });

  return data;
}
```

### Example 1: Twitter Monitor for Specific Project

```javascript
class ProjectTwitterMonitor {
  constructor(projectId, apiKey) {
    this.projectId = projectId;
    this.apiKey = apiKey;
    this.baseUrl = `https://hive.pepes.dog/api/projects/${projectId}`;
  }

  async monitorKeyword(keyword, interval = 60000) {
    let lastTweetId = null;

    setInterval(async () => {
      try {
        const response = await fetch(
          `${this.baseUrl}/twitter/search?q=${encodeURIComponent(keyword)}&count=10`,
          { headers: { 'Authorization': `Bearer ${this.apiKey}` } }
        );

        const data = await response.json();
        const tweets = data.data.tweets;

        if (tweets.length > 0 && tweets[0].id !== lastTweetId) {
          const newTweets = lastTweetId
            ? tweets.filter(t => t.id > lastTweetId)
            : tweets;

          for (const tweet of newTweets) {
            console.log(`[${this.projectId}] New tweet: ${tweet.text}`);

            // Process high engagement tweets
            if (tweet.metrics.like_count > 1000) {
              console.log('High engagement tweet detected!');
              await this.analyzeTweet(tweet);
            }
          }

          lastTweetId = tweets[0].id;
        }
      } catch (error) {
        console.error('Monitor error:', error);
      }
    }, interval);
  }

  async analyzeTweet(tweet) {
    // Get full tweet details with replies
    const response = await fetch(
      `${this.baseUrl}/twitter/tweets/${tweet.id}?include_replies=true`,
      { headers: { 'Authorization': `Bearer ${this.apiKey}` } }
    );

    const data = await response.json();
    console.log(`Tweet has ${data.data.replies.tweets.length} replies`);
  }
}

// Usage
const monitor = new ProjectTwitterMonitor(
  'cmj4h4o5y0000gy04oss0g3o9',
  'bta_0fdd9a3a057ef1c474079a93b04e2515d2ef000e568d80d71e69f0ec57ce4d03'
);
monitor.monitorKeyword('bitcoin');
```

### Example 2: User Analysis for Project

```javascript
class ProjectUserAnalyzer {
  constructor(projectId, apiKey) {
    this.projectId = projectId;
    this.apiKey = apiKey;
    this.baseUrl = `https://hive.pepes.dog/api/projects/${projectId}`;
  }

  async analyzeUser(username) {
    const headers = { 'Authorization': `Bearer ${this.apiKey}` };

    // Get user profile
    const profileResponse = await fetch(
      `${this.baseUrl}/twitter/users/${username}`,
      { headers }
    );
    const profile = await profileResponse.json();

    // Get recent tweets
    const tweetsResponse = await fetch(
      `${this.baseUrl}/twitter/users/${username}/tweets?count=20`,
      { headers }
    );
    const tweets = await tweetsResponse.json();

    // Get follower sample
    const followersResponse = await fetch(
      `${this.baseUrl}/twitter/users/${username}/followers`,
      { headers }
    );
    const followers = await followersResponse.json();

    // Calculate metrics
    const analysis = {
      projectId: this.projectId,
      profile: {
        username: profile.data.username,
        followers: profile.data.followers_count,
        following: profile.data.following_count,
        tweets: profile.data.tweet_count,
        verified: profile.data.verified
      },
      engagement: this.calculateEngagement(tweets.data.tweets),
      followerQuality: this.analyzeFollowers(followers.data.users),
      influence: this.calculateInfluenceScore(profile.data, tweets.data.tweets)
    };

    return analysis;
  }

  calculateEngagement(tweets) {
    const totalEngagement = tweets.reduce((sum, tweet) => {
      return sum + tweet.metrics.like_count +
             tweet.metrics.retweet_count * 2 +
             tweet.metrics.reply_count * 1.5;
    }, 0);

    return {
      averagePerTweet: totalEngagement / tweets.length,
      topTweet: tweets.sort((a, b) =>
        b.metrics.like_count - a.metrics.like_count
      )[0]
    };
  }

  analyzeFollowers(followers) {
    const verifiedCount = followers.filter(f => f.verified).length;
    const avgFollowers = followers.reduce((sum, f) =>
      sum + f.followers_count, 0
    ) / followers.length;

    return {
      verifiedPercentage: (verifiedCount / followers.length) * 100,
      averageFollowerCount: avgFollowers,
      quality: avgFollowers > 1000 ? 'High' : 'Medium'
    };
  }

  calculateInfluenceScore(profile, tweets) {
    const followerScore = Math.log10(profile.followers_count + 1) * 10;
    const engagementRate = tweets.reduce((sum, t) =>
      sum + (t.metrics.like_count / profile.followers_count), 0
    ) / tweets.length * 100;
    const verifiedBonus = profile.verified ? 20 : 0;

    return Math.min(100, followerScore + engagementRate + verifiedBonus);
  }
}
```

### Example 3: Multi-Project Management

```javascript
class MultiProjectManager {
  constructor(projects) {
    // projects = [{ id: 'proj1', apiKey: 'key1' }, ...]
    this.projects = projects;
  }

  async searchAcrossProjects(query) {
    const promises = this.projects.map(async (project) => {
      const response = await fetch(
        `https://hive.pepes.dog/api/projects/${project.id}/twitter/search?q=${encodeURIComponent(query)}`,
        { headers: { 'Authorization': `Bearer ${project.apiKey}` } }
      );

      const data = await response.json();
      return {
        projectId: project.id,
        tweets: data.data.tweets
      };
    });

    const results = await Promise.all(promises);

    // Aggregate results
    const allTweets = results.flatMap(r =>
      r.tweets.map(t => ({ ...t, projectId: r.projectId }))
    );

    // Sort by engagement
    return allTweets.sort((a, b) =>
      b.metrics.like_count - a.metrics.like_count
    );
  }

  async compareUserAcrossProjects(username) {
    const promises = this.projects.map(async (project) => {
      try {
        const response = await fetch(
          `https://hive.pepes.dog/api/projects/${project.id}/twitter/users/${username}`,
          { headers: { 'Authorization': `Bearer ${project.apiKey}` } }
        );

        if (!response.ok) return null;

        const data = await response.json();
        return {
          projectId: project.id,
          user: data.data
        };
      } catch (error) {
        console.error(`Error for project ${project.id}:`, error);
        return null;
      }
    });

    const results = await Promise.all(promises);
    return results.filter(r => r !== null);
  }
}
```

When building an SDK for the Projects API:

### 1. Core Features

- Authentication handling
- Automatic retry logic
- Response caching
- Pagination helpers
- Error handling

```javascript
class ProjectsSDK {
  constructor(projectId, apiKey, options = {}) {
    this.projectId = projectId;
    this.apiKey = apiKey;

    this.cache = options.cache || new Map();
    this.maxRetries = options.maxRetries || 3;
  }

  // Core methods
  async request(path, options = {}) {
    const url = `${this.baseUrl}${path}`;
    const config = {
      ...options,
      headers: {
        'Authorization': `Bearer ${this.apiKey}`,
        ...options.headers
      }
    };

    // Add retry logic here
    return this.requestWithRetry(url, config);
  }

  // Twitter data methods
  twitter = {
    searchTweets: (query, options) => this.request('/twitter/search', {

    }),

      params: { q: query, ...options }
    }),
    getUser: (username) => this.request(`/twitter/users/${username}`),

      params: { cursor }
    }),

      params: options
    })
  };
```

## Security Best Practices

### 1. API Key Management

- **Never** expose API keys in client-side code
- Use environment variables
- Rotate API keys regularly
- Use different keys for different environments

### 2. Project ID Validation

- Always validate project ID format
- Ensure project ID belongs to authenticated user
- Never accept project ID from untrusted sources

### 3. Request Validation

- Validate all input parameters
- Sanitize user input
- Implement request size limits
- Use HTTPS for all API calls

## Troubleshooting

### Common Issues and Solutions

1. **401 Unauthorized**
   - Check API key is correct
   - Verify Bearer token format: `Bearer <token>`
   - Ensure project ID is valid

2. **404 Not Found - Invalid projectId**
   - Verify project ID is in the URL path
   - Check project ID format
   - Ensure project exists

3. **502 Bad Gateway**
   - TwitterAPI.io temporary issue
   - Implement retry with exponential backoff

4. **Empty Response Data**
   - User might not exist
   - Tweet might be deleted
   - Search query might have no results

5. **Incorrect URL Structure**
   - Remember: projectId goes in the path, not query params
   - Format: `/api/projects/{projectId}/...`

## Migration Guide

### From Query Parameter to Path Parameter

If you were incorrectly using projectId as a query parameter:

```javascript
// ❌ OLD (WRONG)
const oldUrl = `https://hive.pepes.dog/api/projects/twitter/search?projectId=${projectId}&q=bitcoin`;

// ✅ NEW (CORRECT)
const newUrl = `https://hive.pepes.dog/api/projects/${projectId}/twitter/search?q=bitcoin`;
```

### Update Your Code

```javascript
// Before
function buildUrl(endpoint, projectId, params) {
  const url = new URL(`https://hive.pepes.dog/api/projects${endpoint}`);
  url.searchParams.set('projectId', projectId);
  Object.entries(params).forEach(([key, value]) => {
    url.searchParams.set(key, value);
  });
  return url.toString();
}

// After
function buildUrl(endpoint, projectId, params) {
  const url = new URL(`https://hive.pepes.dog/api/projects/${projectId}${endpoint}`);
  Object.entries(params).forEach(([key, value]) => {
    url.searchParams.set(key, value);
  });
  return url.toString();
}
```
